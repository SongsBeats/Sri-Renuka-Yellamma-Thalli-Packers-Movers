# Sri Renuka Yellamma Thalli Packers & Movers

Premium brand website for a packing and moving business based in Karmanghat, Hyderabad.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- React Router
- Lucide React

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## Pages

- `/` — Home (conversion-focused)
- `/services` — Services detail
- `/about` — About the business
- `/service-areas` — Hyderabad coverage areas
- `/contact` — Contact + quote form
- `/privacy` — Privacy policy

## Enquiries

Quote requests open a pre-filled WhatsApp conversation to `+91 77994 51430`. No backend database is used.
